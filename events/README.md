# Events

This directory is intentionally trimmed to the active workshop set for the `Cognition-Partner-Workshops-mirror` organization:

- **Primary event:** [`2026-05-07-workshop/`](2026-05-07-workshop/) — the main hands-on event for Java/Spring Boot, monolith-to-microservices, ETL, Ab Initio, and workflow-oriented teams
- **Specialized alternatives:** focused tracks for security automation, platform decomposition, COBOL modernization, and Oracle Forms modernization

## Active Event Set

| Event | Focus | Best For |
|-------|-------|----------|
| [2026-05-07-workshop](2026-05-07-workshop/) | Java/Spring Boot, API-first development, monolith-to-microservices, ETL modernization | Mixed engineering audiences; the default event |
| [enterprise-demo-track](enterprise-demo-track/) | Autonomous security remediation and enterprise-scale orchestration | AppSec, platform, engineering leadership |
| [platform-microservice-decomposition](platform-microservice-decomposition/) | Platform-conformant service extraction with IaC | Platform teams, solution architects, microservices programs |
| [cobol-modernization-workshop](cobol-modernization-workshop/) | COBOL discovery, migration planning, and Java translation | Mainframe modernization teams |
| [oracle-forms-modernization-workshop](oracle-forms-modernization-workshop/) | Oracle Forms / PL/SQL modernization to Java | Legacy enterprise application teams |

## Workshop vs. Event

- **Workshops** (`workshops/`) are reusable reference templates for the specialized alternatives.
- **Events** (`events/`) are the concrete workshop instances participants run.
- The **2026-05-07** event is the primary entry point; the others are narrower alternatives for teams that want a role-specific track.

See [`workshops/README.md`](../workshops/README.md) for the retained workshop templates.
